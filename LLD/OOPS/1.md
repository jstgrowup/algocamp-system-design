## 1. Introduction & Overview of OOP

- **What is Object-Oriented Programming (OOP)?**
- A programming paradigm that uses classes and objects to model real-world entities, promoting code reusability, modularity, and easier maintenance.

- **Course Roadmap:** Overview of upcoming topics in the series, including classes, objects, constructors, inheritance, polymorphism, encapsulation, abstraction, exception handling, collections framework, and file handling.

---

## 2. Classes and Objects

- **Class:**
- A blueprint or template used to create objects. It defines properties (instance variables/attributes) and behaviors (methods/functions).
- _Example used in video:_ Creating a custom student data structure. Instead of maintaining separate individual variables for every student, a `Student` class is defined:

```java
class Student {
    int rollNo;
    String name;
    float marks;
}

```

- **Object:**
- An instance of a class that occupies physical memory. It has:

1. **State:** Represented by the attributes/properties (e.g., name, roll number, marks).
2. **Behavior:** Represented by methods (what the object can do).
3. **Identity:** How the object is uniquely recognized in memory.

## 3. Memory Allocation & Dynamic Dispatch

- **Stack vs. Heap Memory:**
- **Stack Memory:** Stores primitive data types, method frames, and reference variables (pointers to objects).
- **Heap Memory:** Dynamically allocates memory at runtime for the actual objects created using the `new` keyword.

- **The `new` Keyword:**
- Dynamically allocates memory at runtime for an object and returns a reference to it.

- **Why Primitives Don't Use `new`:**
- Primitives (like `int`, `char`, `boolean`) are stored directly on the stack for performance optimization and speed, avoiding heap allocation overhead.

## 4. Constructors

- **Definition:** A special method invoked automatically when an object is instantiated, used to initialize object properties.
- **Default Constructor:** Provided automatically by Java if no explicit constructor is defined, assigning default values (e.g., `0` for numbers, `null` for objects).
- **Parameterized Constructor:** Allows passing custom values during object creation to initialize fields directly.
- _Example:_

```java
Student(int roll, String name, float marks) {
    this.rollNo = roll;
    this.name = name;
    this.marks = marks;
}

```

- **The `this` Keyword:**
- A reference variable that points to the current object whose method or constructor is being invoked. Used to resolve shadowing issues when parameter names match instance variable names.

- **Constructor Overloading:**
- Having multiple constructors with different parameter lists within the same class.

- **Calling One Constructor from Another (`this()`):**
- Reusing constructor logic by invoking another constructor using `this(...)`.

---

## 5. Wrapper Classes

- **Definition:** Classes that wrap primitive data types into objects (e.g., `Integer` for `int`, `Float` for `float`, `Double` for `double`).
- **Why Use Wrapper Classes?**
- Enables primitives to be used in collections (like `ArrayList`), which only accept objects, and provides utility methods.

- **Autoboxing and Unboxing:**
- Automatic conversion between primitives and their corresponding wrapper classes by the Java compiler.

---

## 6. Keywords

- **The `final` Keyword:**
- Used to restrict the user.
- _On variables:_ Makes the variable a constant (value cannot be reassigned). _Note:_ For object references marked `final`, internal properties can still change, but the reference cannot point to a new object.

- **Garbage Collection:**
- Automatic memory management in Java where the Garbage Collector destroys unreferenced objects in the heap to free up system memory.
- **`finalize()` method:** Historically used to perform clean-up tasks before an object is destroyed by the garbage collector (though deprecated/superseded in modern Java versions).
