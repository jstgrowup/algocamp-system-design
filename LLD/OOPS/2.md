## 1. Packages

- **What are Packages?**
- Containers or folders used to group related classes, interfaces, and sub-packages together. They prevent naming conflicts and help organize large codebases.

- **Built-in Packages vs. User-defined Packages:**
- _Built-in:_ Provided by Java (e.g., `java.util`, `java.io`, `java.lang`).
- _User-defined:_ Created by developers to structure their applications logically (e.g., `com.kunal.introduction`, `com.kunal.properties`).

- **How Packages Work:**
- The directory structure of your project matches the package hierarchy.
- The `package` keyword is used at the top of a file to declare its package.
- The `import` keyword is used to access classes from other packages.

## 2. The `static` Keyword

- **Definition:**
- A keyword used to manage memory efficiently. When a member is declared `static`, it belongs to the **class** itself rather than to any specific instance (object) of the class.

- **Static vs. Instance Variables:**
- **Instance Variables:** Separate copies exist for every individual object created in heap memory.
- **Static Variables (Class Variables):** Only a single copy is shared across all objects of that class. Changes made to a static variable by one object reflect across all other objects.

- **Static Methods:**
- Can be called directly using the class name without needing to instantiate an object (e.g., `Math.max()`, `Main.main()`).
- **Key Rule:** A static method can _only_ access other static data members and static methods directly. It cannot use `this` or `super` keywords because `this` refers to a specific instance, which doesn't exist for static contexts.

- **Why `main` Method is Static:**
- The Java Virtual Machine (JVM) needs to call the `main` method before any objects of the class are created. Making it `static` allows the JVM to execute it directly via the class name.

- **Static Blocks:**
- Used for initializing static variables. A static block runs **only once** when the class is first loaded into memory (before any objects are created).
- _Example:_

```java
static {
    System.out.println("Static block runs once when class is loaded");
    b = a * 5;
}

```

## 3. Singleton Class

- **Definition:**
- A design pattern that restricts the instantiation of a class to **exactly one object**.

- **How to Implement a Singleton Class in Java:**

1. Make the constructor **private** so that other classes cannot use the `new` keyword to create instances freely.
2. Create a `private static` instance of the class inside the class itself.
3. Provide a `public static` method (often called `getInstance()`) to return that single instance safely.

- **Example Concept:**

```java
public class Singleton {
    private static Singleton instance;

    private Singleton() {
        // Private constructor prevents outside instantiation
    }

    public static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}

```

## 4. In-built Methods & Code Exploration

- **Exploring Java's Internal Source Code:**
- Kunal demonstrates how to command-click or navigate into built-in Java classes (like `String`, `System`, or `Integer`) inside an IDE (like IntelliJ IDEA) to examine how core Java methods are written under the hood.

- **Understanding `System.out.println()`:**
- Breaking down the components:
- `System`: A final built-in class in the `java.lang` package.
- `out`: A `public static final` reference variable of type `PrintStream` declared inside the `System` class.
- `println()`: A method belonging to the `PrintStream` class used to output data to the console.
