## 1. Abstract Classes & Abstract Methods

- **What is an Abstract Method?**
- A method declared with the `abstract` keyword **without a body** (no implementation `{}`).
- It acts as a mandatory template/contract: any child class that extends the abstract class **must** override and provide an implementation for all abstract methods.

- **What is an Abstract Class?**
- A class declared with the `abstract` keyword. If a class contains one or more abstract methods, the class itself **must** be declared abstract.
- **Key Rules & Constraints:**

1. **Cannot be Instantiated:** You cannot create an object of an abstract class using the `new` keyword (e.g., `Parent p = new Parent();` is invalid). This is because abstract classes contain incomplete methods (methods without bodies), so calling them directly would lead to errors.
2. **Constructors:** Abstract classes _can_ have constructors, which are called via `super()` when a child class is instantiated.
3. **Static Methods:** Abstract methods _cannot_ be static because static methods belong to the class and cannot be overridden. However, abstract classes can contain regular static methods.
4. **Final Classes:** An abstract class cannot be declared `final`, because `final` prevents inheritance, whereas an abstract class _must_ be inherited and implemented to be useful.

## 2. Why Java Doesn't Support Multiple Inheritance with Classes

- **The Diamond Problem:**
- If a class `C` were allowed to extend two parent classes (`A` and `B`) that both implement a method with the same signature, the compiler wouldn't know which version of the method to inherit. To avoid this ambiguity and maintain code safety, Java **does not support multiple inheritance with classes**.

## 3. Interfaces in Java

- **What is an Interface?**
- A reference type in Java similar to a class that is used to achieve **100% abstraction** and support **multiple inheritance**.
- Contains abstract methods by default (prior to Java 8), constants (`public static final` variables), and static/default methods (from Java 8 onwards).

- **Key Characteristics of Interfaces:**
- **No Instantiation:** Like abstract classes, you cannot create direct objects of an interface.
- **Variables:** All variables declared in an interface are implicitly `public`, `static`, and `final` (constants).
- **Methods:** All methods are implicitly `public` and `abstract` by default.
- **The `implements` Keyword:** Classes use the `implements` keyword to inherit from an interface.

```java
class Car implements Engine, Brake {
    // Must override all methods from both interfaces
}

```

- **Supporting Multiple Inheritance:**
- A Java class can implement **multiple interfaces simultaneously**, solving the limitation of classes only extending a single superclass.

- **Interface-to-Interface Inheritance:**
- An interface can inherit from another interface using the `extends` keyword (e.g., `interface B extends A`).

---

## 4. Advanced Interface Features (Java 8+ Features)

- **Default Methods (`default` keyword):**
- Introduced in Java 8 to allow developers to add new methods to an interface with a default implementation without breaking existing classes that implement that interface.

- **Static Methods in Interfaces:**
- Interfaces can contain static methods with a body. These methods belong strictly to the interface itself and cannot be overridden by implementing classes; they must be called using the interface name (e.g., `InterfaceName.methodName()`).

---

## 5. Abstract Classes vs. Interfaces (Comparison)

| Feature          | Abstract Class                                                                   | Interface                                                                               |
| ---------------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **Inheritance**  | Can extend **only one** class.                                                   | Can implement **multiple** interfaces.                                                  |
| **Methods**      | Can have both abstract and concrete (implemented) methods.                       | Traditionally only abstract methods (plus `default` & `static` methods in modern Java). |
| **Variables**    | Can have instance variables, static variables, `final`, and non-final variables. | Variables are strictly `public static final` (constants).                               |
| **Constructors** | Can have constructors.                                                           | Cannot have constructors.                                                               |
| **Speed**        | Slightly faster performance.                                                     | Slightly slower due to interface lookups.                                               |

---

## 6. Annotations & Nested Interfaces

- **Annotations (`@Override`, etc.):**
- Metadata that provides data about the program to the compiler or runtime (e.g., `@Override` ensures a method is correctly overriding a superclass/interface method).

- **Nested Interfaces:**
- An interface declared inside another class or interface. They can be public, protected, or private depending on where they are nested.
