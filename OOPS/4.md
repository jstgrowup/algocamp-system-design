## 1. Access Control / Access Modifiers

- **What is Access Control?**
- Mechanisms in Java used to restrict where variables, methods, and constructors can be accessed or modified within a project, ensuring data security and proper encapsulation.

- **The 4 Access Modifiers in Java:**

1. **`private`:**

- Accessible _only_ within the declared class itself. Cannot be accessed from anywhere else, providing strict data hiding.

2. **Default (No modifier specified):**

- Accessible only within classes residing in the **same package**. Cannot be accessed from outside the package.

3. **`protected`:**

- Accessible within the same package _and_ in subclasses (child classes) located in **different packages** (via inheritance).

4. **`public`:**

- Accessible from **anywhere** across all packages and classes.

- **Summary Access Table:**

| Access Modifier | Within Class | Within Package | Subclass (Different Package) | Everywhere (World) |
| --------------- | ------------ | -------------- | ---------------------------- | ------------------ |
| **`private`**   | Yes          | No             | No                           | No                 |
| **Default**     | Yes          | Yes            | No                           | No                 |
| **`protected`** | Yes          | Yes            | Yes (via inheritance)        | No                 |
| **`public`**    | Yes          | Yes            | Yes                          | Yes                |

- **Why Use Getters and Setters?**
- Since private fields (`private int num`) cannot be accessed directly via object reference (`obj.num`), we use `public` getter and setter methods (`getNum()`, `setNum()`) to safely inspect or modify private values while maintaining encapsulation.

## 2. In-built Packages in Java

Kunal explores the standard packages provided by the Java API (`java.lang`):

- **`java.lang`:**
- Automatically imported into every Java program. Contains fundamental classes like `System`, `String`, `Integer`, `Math`, and `Object`.

- **`java.io`:**
- Handles input and output operations (reading/writing files, streams).

- **`java.util`:**
- Contains utility classes, data structures, and the **Collections Framework** (e.g., `ArrayList`, `HashMap`, `HashSet`).

- **`java.applet` / `java.awt` / `javax.swing`:**
- Older or specialized libraries used for Graphical User Interfaces (GUIs), buttons, windows, and graphics.

- **`java.net`:**
- Handles networking operations (sockets, URLs, connections).

## 3. The `Object` Class in Java

- **Definition:**
- The `Object` class (part of `java.lang`) is the **root parent class of all classes** in Java. Every class you create implicitly or explicitly extends `Object`.

- **Key Methods in the `Object` Class:**

1. **`toString()`:**

- Returns a string representation of the object (by default, hashcode/memory address representation, which is typically overridden to show clean field values).

2. **`hashCode()`:**

- Returns a unique integer representation (hash value) generated by an internal algorithm to represent the object's identity in memory.

3. **`equals()`:**

- Compares two objects. By default, `==` and `equals()` in the base `Object` class check reference equality (whether both reference variables point to the exact same object in memory). Developers often override `equals()` to check **content equality** instead.

4. **`getClass()`:**

- Returns the runtime class type of an object (`Class<?>`), allowing inspection of metadata at runtime.

5. **`instanceof` operator vs `getClass()`:**

- `instanceof` checks if an object is an instance of a specific class or its subclasses.
