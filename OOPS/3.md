## 1. Overview of the 4 Pillars of OOP

Kunal introduces the core pillars that form the foundation of Object-Oriented Programming:

1. **Inheritance**
2. **Polymorphism**
3. **Encapsulation**
4. **Abstraction**

## 2. Inheritance

- **Definition:**
- The mechanism by which one class (child class / subclass) inherits the properties (variables) and methods (behaviors) of another class (parent class / superclass).

- **Key Benefits:**
- Code reusability, extensibility, and establishing a relationship hierarchy between classes.

- **The `extends` Keyword:**
- Used in Java to signal that a child class is inheriting from a parent class.

```java
class ChildClass extends ParentClass {
    // Additional properties and methods
}

```

- **Real-World / Code Example:**
- Creating a base `Box` class with properties like `length`, `width`, and `height`, and then creating a `BoxWeight` subclass that extends `Box` to add a `weight` property.

- **The `super` Keyword:**
- Used inside a subclass to reference its immediate parent class.
- Commonly used in constructors to pass parameters up to the parent class constructor for proper initialization.

```java
BoxWeight(double l, double w, double h, double weight) {
    super(l, w, h); // calls parent class constructor
    this.weight = weight;
}

```

- **Types of Inheritance in Java:**
- **Single Inheritance:** One subclass inherits from one superclass.
- **Multilevel Inheritance:** A chain of inheritance (e.g., Class C extends Class B, which extends Class A).
- **Hierarchical Inheritance:** Multiple subclasses inherit from a single superclass.
- _Note on Multiple & Hybrid Inheritance:_ Java **does not** support multiple inheritance with classes directly (to avoid the Diamond Problem) and instead implements it using **Interfaces**.

## 3. Polymorphism

- **Definition:**
- Meaning "many forms", polymorphism allows a single action or method to behave differently based on the object or context calling it.

- **Types of Polymorphism in Java:**

1. **Compile-time Polymorphism (Static Polymorphism):**

- Achieved via **Method Overloading**. The method to be executed is decided by the compiler based on method signatures (arguments/parameters).

2. **Run-time Polymorphism (Dynamic Polymorphism):**

- Achieved via **Method Overriding**. It happens when a subclass provides a specific implementation of a method that is already defined in its parent class. The decision on which method to run is made dynamically at runtime by the JVM based on the object type, not the reference type.

- **Dynamic Method Dispatch:**
- A mechanism where a call to an overridden method is resolved at runtime rather than compile-time (e.g., Parent reference pointing to a Child object: `Parent obj = new Child();`).

- **The `final` Keyword & Inheritance/Polymorphism:**
- Declaring a class as `final` prevents it from being inherited.
- Declaring a method as `final` prevents it from being overridden by subclasses.

---

## 4. Encapsulation

- **Definition:**
- The wrapping up of data (variables) and code (methods) acting on the data into a single unit (class). It also involves **data hiding** by restricting direct access to certain components.

- **How It's Achieved:**
- Declaring instance variables as `private` so they cannot be accessed directly from outside the class.
- Providing `public` **getter** and **setter** methods to safely view or modify those private values.

- **Real-World Analogy:**
- A medicine capsule: the chemical components are hidden inside a protective shell, and you interact with it through defined guidelines.

---

## 5. Abstraction

- **Definition:**
- The concept of hiding complex implementation details and showing only the essential features/functionality to the user.

- **How It's Achieved in Java:**
- Using **Abstract Classes** and **Interfaces**.
- An abstract class cannot be instantiated directly and can contain abstract methods (methods without a body that _must_ be implemented by subclasses) as well as regular concrete methods.
