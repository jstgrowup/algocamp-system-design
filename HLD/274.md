## Domain Name System

- One mobile is related to one phone number, right? That's unique
- So there we can have a phone book
- Computers are identified by a unique IP address
- An IP is a unique number given to a device
- DNS is nothing but an internet phone book
- It keeps a mapping of the domain names
- We can't remember the IP
- DNS does the job for us: it translates human-readable addresses to IP addresses
- DNS infra has an internet handbook
- DNS will return the IP address and the user will be redirected to that IP
- Everyone needs a group of servers
- These servers are called Name Servers
- Resource records:
  - These are individual records
  - A resource record is the smallest record in the DNS DB, the smallest unit in the DNS
- Name servers and resource records together allow DNS to effectively act as a lookup system, helping users reach the right websites or services on the internet
- Three main components of a resource record: Type, Name, Value
- Some types of resource records in DNS:
  - A record - IPv4 (32-bit address)
  - AAAA record - IPv6 (128-bit address)
  - CNAME record - Canonical Name record. An alias for another domain name, helping redirect one domain to another
  - MX record - SMTP mail servers responsible for receiving emails for a domain
- The IP address of a device can change when it is connected to a different network, because most devices are assigned dynamic addresses
- DNS is just a mapping, it doesn't allocate you an IP
- DNS is like a domain name being registered
- No two people will register the same domain
